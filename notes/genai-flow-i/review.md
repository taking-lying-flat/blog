# GenAI-Flow-I 发布核验

原始桌面导出文件按字节保存在 `source.lake`，SHA-256、卡片顺序及原始资源校验值见 `manifest.json`。网页保留原文的标题、段落、强调、颜色、列表及图片尺寸；经核验的内容修正由 `math-overrides.json` 和 `text-overrides.json` 应用，原始导出文件不改写。每项修正包含原文、替换内容、理由和参考资料。

## 内容复核

对照 [Variational Inference with Normalizing Flows](https://proceedings.mlr.press/v37/rezende15.pdf)、[Neural Ordinary Differential Equations](https://arxiv.org/html/1806.07366v5) 和 [FFJORD](https://arxiv.org/html/1810.01367v2)，并对原文中互相矛盾的公式独立推导。原论文也存在部分记号或公式笔误，修正依据不只是逐字比对论文。

- 分层潜变量分布显式写出顶层先验；平面流雅可比在变换输入处求值，并明确可逆性条件和位移方向。
- 径向流行列式补回径向导数项的 beta 系数，明确参数约束；Wiener 协方差、Langevin 能量符号与 Hamiltonian 质量矩阵约定保持一致。
- 伴随正文统一采用行向量，补回反向参数梯度积分的负号、缺失的积分微分和时间伴随终端条件。
- 连续密度演化使用负空间散度，区分沿轨迹总导数与固定位置的时间偏导；补回 ODE 终态表达式中的初始状态。
- 区分对数密度与密度的无偏性、一次 ODE 求解与一次网络求值，并说明瓶颈方差改善和简化复杂度计数的适用范围。

## 验证结果

完整结果见 `verification.json`。

- 363 个原始公式卡片、8 张图片、14 个标题均按顺序保留；另有 3 个用于补充条件和复杂度说明的行内公式。
- 263 个原始资源通过 SHA-256 和 SVG/图片解析校验。网页无需访问语雀 CDN。
- 除已记录的修正外，文本及 1,012 个原始结构/格式元素逐项匹配。
- 径向流行列式、两层平面流复合雅可比通过有限差分核验；非自治标量 ODE 的参数梯度和初始时间梯度与解析解、有限差分一致；线性流密度变化及 Hutchinson 期望独立核验通过。
- Chrome 检查 320、390、768、1024、1280、1440 像素宽度，未发现图片加载失败、页面横向溢出或浏览器报错；长公式可横向滚动到右端，深色主题及首页入口可用。
- 桌面断行检查未发现短尾行；320 像素下记录了一个约 42 像素宽的末行，内容完整且未溢出。
- 原有 11 篇文章的正文和公式图形与发布前构建一致。MathJax 的全局 SVG 编号会因新增文章变化，比较时仅归一化该编号。
- `npm run build` 和 `git diff --check` 通过。

这些检查覆盖导入完整性、已识别的数学问题、页面排版和构建回归；数值例子用于交叉核验相关公式，不替代其一般性推导。
