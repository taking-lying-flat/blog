# FLASH-ATTN 发布核验

桌面语雀导出文件按字节保存为 `source.lake`。原始资源、尺寸与 SHA-256 校验值见 `manifest.json`。沿用博客现有正文衬线字体、公式字体、行内公式间距与段落换行规则，无全站样式修改。

## 公式修正

仅通过 `math-overrides.json` 修正三处公式；原始导出文件及全部原始 SVG 保持不变，正文文字不改写。

- `oUoLN`：将反向传播的 `dK = Q dS^T` 改为 `dK = dS^T Q`，修正矩阵乘法顺序及维度错误。
- `fD9rR`：归一化输出更新中，旧输出的系数改为 `(ell^(1) / ell^(2)) exp(m^(1) - m^(2))`，删除错误的逆幂，并补齐最大值变化对应的重缩放。
- `hr43S`：未归一化输出更新改为使用 `diag(exp(m^(1) - m^(2)))` 缩放上一块的未归一化输出，再加上当前块贡献，与文中随后给出的完整递推式一致。

依据 [FlashAttention-2 会议版](https://openreview.net/notes/edits/attachment?id=AOJZxmW2Zt&name=pdf)第 2.2 节及 Algorithm 1 第 9–12 行核对。会议论文正文两处简写本身也有缩放遗漏或笔误，因此后两项依据完整算法、矩阵维度及数值等价核验修正，不直接照抄简写。
